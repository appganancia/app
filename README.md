# AppGanancia

Apps para la vendedora por catálogo: sus ventas, quién le debe y cuánto le quedó.
Funcionan en el navegador del celular, sin instalar nada y sin mensualidad.

- `hub.html`: menú de las apps (página de inicio)
- `index.html`: Mis Ventas
- `divulga.html`: Mensajes listos

Contenido estático, sin servidor y sin base de datos. Los datos de cada usuaria
se quedan en su propio celular.
